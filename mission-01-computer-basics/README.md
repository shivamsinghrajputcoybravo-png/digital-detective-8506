







# Task 1.1: Tracing One Activity Using IPOS

Chosen Activity:Typing and saving a document:-

| Stage | What happens? | Hardware component |
|---|---|---|
| Input | Text is entered using the keyboard. | Keyboard |
| Processing | The computer processes the typed text. | CPU and RAM |
| Output | The computer displays the text on the screen. | Monitor |
| Storage | The document is saved for future use. | SSD |




# Task 1.2: Identify hardware and software

| Hardware component | Category / Type | Purpose |
|---|---|---|
| Keyboard | Input Device | Used to enter text and commands. |
| Mouse | Input Device | Used to point, click and select items. |
| Monitor | Output Device | Displays text, images and videos. |
| SSD | Storage Device | Stores files and data for future use. |
| CPU | Processing Device | Processes data and executes instructions. |



| Software | Category | Purpose |
|---|---|---|
| Windows | Operating System | Manages computer hardware and software. |
| macOS | Operating System | Manages computer resources and provides a user interface. |
| Google Chrome | Application Software | Used to browse the internet. |
| MS Word | Application Software | Used to create and edit documents. |
| Antivirus | Utility Software | Helps protect the computer from malware and viruses. |
| Disk Cleanup | Utility Software | Helps remove unnecessary files. |
