## Task 4.2: Compiler vs Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the source code before execution. | Executes instructions at runtime. |
| Typical output | Often generates a separate executable or machine code. | Usually executes without creating a separate executable file. |
| One example | C, C++ | Python (commonly described as interpreted) |
| One advantage | Compiled programs can run efficiently. | Makes testing and debugging convenient. |

### My Understanding

A compiler translates source code into another form before the program runs. An interpreter executes instructions at runtime. A compiler often creates a separate executable, while an interpreter usually runs the program through its execution environment. Python commonly uses an interpreter, although its implementation also involves compilation to bytecode.
